# opencode

OpenCode (catalog agent `opencode`) is an open-source coding agent with a terminal UI, a
background server and, on the 2.0 line, an Electron desktop app; its repository moved from
`sst/opencode` to `anomalyco/opencode` ([section 1](#1-source-and-evidence)). The transcript
schema, and the agents that share or fork its store, are in
[`analyzer/research/opencode.md`](../../analyzer/research/opencode.md); not repeated here.

## 2. Per-user storage

[`packages/core/src/global.ts:3`](https://github.com/sst/opencode/blob/907b3bc518fa48e90e8ec24dd327d13eee71c36c/packages/core/src/global.ts#L3),[`10-15`](https://github.com/sst/opencode/blob/907b3bc518fa48e90e8ec24dd327d13eee71c36c/packages/core/src/global.ts#L10-L15) builds data, cache, config and state as `xdg*/opencode`. [`xdg-basedir/index.js:7-16`](https://github.com/sindresorhus/xdg-basedir/blob/8cceade858e4da18cb971bf1844f086e9e213563/index.js#L7-L16) has no platform branch: `XDG_DATA_HOME` or `~/.local/share`, `XDG_CONFIG_HOME` or `~/.config`, `XDG_STATE_HOME` or `~/.local/state`, `XDG_CACHE_HOME` or `~/.cache`. So the layout is identical on Linux, macOS and Windows (`%USERPROFILE%\.local\share\opencode` etc.). Home itself comes from `OPENCODE_TEST_HOME` or `os.homedir()` ([`global.ts:19`](https://github.com/sst/opencode/blob/907b3bc518fa48e90e8ec24dd327d13eee71c36c/packages/core/src/global.ts#L19)).

### Scratch directories

OpenCode 2.0 creates `<os.tmpdir()>/opencode` at start and tells the model in its environment block to prefer it over `/tmp`, as a directory "pre-created and approved for external access" ([`packages/util/src/global-roots.ts:17`](https://github.com/anomalyco/opencode/blob/cb07c555d4d1ca34430b7857b52f104c3d95e09e/packages/util/src/global-roots.ts#L17), [`packages/util/src/global.ts:66-72`](https://github.com/anomalyco/opencode/blob/cb07c555d4d1ca34430b7857b52f104c3d95e09e/packages/util/src/global.ts#L66-L72), [`packages/core/src/instructions/builtins.ts:43`](https://github.com/anomalyco/opencode/blob/cb07c555d4d1ca34430b7857b52f104c3d95e09e/packages/core/src/instructions/builtins.ts#L43)). It is `/tmp/opencode` on Linux, under `/var/folders` on macOS and `%TEMP%\opencode` (`AppData\Local\Temp\opencode`) on Windows, so outside the home on Linux and macOS, where no catalog line can reach it, and under the home but unclaimed by any catalog line on Windows; the same gap as Claude Code's temp root (issue 163). The worktrees OpenCode makes for a project are scratch directories inside the data directory ([`packages/core/src/worktree/strategies.ts:51`](https://github.com/anomalyco/opencode/blob/cb07c555d4d1ca34430b7857b52f104c3d95e09e/packages/core/src/worktree/strategies.ts#L51)); the catalog excludes their contents (`.local/share/opencode/worktree`), and since `.local/share/opencode` is a catalog entry the analyzer's catalog rule already lists a session working there as a scratch directory rather than a project.
